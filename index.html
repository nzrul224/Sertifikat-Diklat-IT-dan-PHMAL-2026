Aplikasi ini dirancang untuk membaca data peserta dari **Google Spreadsheet** dan file sertifikat PDF dari **Google Drive** secara *live*.

Langkah Memasang URL Web App API:

  1. Buka Google Apps Script Backend (`Code.gs`) Anda.
  2. Klik tombol **Deploy > New deployment > Web app**.
  3. Atur **Execute as** = Me & **Who has access** = Anyone.
  4. Salin **Web App URL** yang dihasilkan.
  5. Buka file index.html ini dengan teks editor, lalu tempelkan URL tersebut pada baris teratas skrip pada variabel API_URL.

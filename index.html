Checklist Wajib Jika Tes API Gagal:

  • Buka Apps Script > Deploy > Manage deployments.

  • Pastikan Who has access = Anyone (Wajib!).
  • Jika mengubah kode di Apps Script, wajib pilih New version saat Deploy ulang.

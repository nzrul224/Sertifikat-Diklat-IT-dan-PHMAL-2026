Struktur Kolom & Alur PDF Tanpa Template

1. Pastikan baris pertama (Header) Google Spreadsheet Anda menggunakan nama kolom berikut:

1. No. Sertifikat
2. NAMA PESERTA
3. STATUS KEPESERTAAN
4. PROVINSI
5. KABUPATEN dan KOTA
6. STATUS
7. LINK PDF
8. JUMLAH UNDUH

Cara Menggunakan File PDF yang Sudah Ada di Google Drive:

1. Unggah semua berkas PDF sertifikat Anda ke dalam satu folder Google Drive.

2. Beri nama file PDF sesuai No. Sertifikat (contoh: CERT-2026-001.pdf) atau sesuai Nama Peserta (contoh: Budi Santoso.pdf).

3. Salin ID Folder Drive ke variabel PDF_FOLDER_ID pada skrip Code.gs.

4. Pada Google Sheet, jalankan menu: 📜 CertiFetch Admin > 🔗 Sinkronkan Link PDF dari Folder Google Drive.

5. Script akan otomatis mencocokkan file PDF, mengatur hak akses public, dan memasukkan link PDF ke spreadsheet!

Catatan Tambahan:

• Kolom JUMLAH UNDUH akan terus bertambah secara otomatis (+1) setiap kali peserta mengunduh berkas dari portal web.
